# Changelog

Версионирование: семантическое (MAJOR.MINOR.PATCH).
- **MINOR** — новый блок функционала (крупные блоки ведутся в отдельной ветке `feat/*`, затем мерж в `dev`).
- **PATCH** — отдельный коммит/правка внутри блока.
- Каждой версии соответствует git-тег `vX.Y.Z`.

Ветки: `main` (стабильная), `dev` (интеграция), `feat/*` (крупные блоки 13–20).
